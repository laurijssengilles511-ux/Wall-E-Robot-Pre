# 瓦力整机虚拟装配

`#/virtual` 提供整机旋转查看、八组关节滑块、八种预设动作、时间轴编排和全屏工作台，以及前、侧、后三张初始姿态的静态视图。模型建立在52类原始STL上，位置、连接和运动范围按现有资料推定，属于展示重建，未通过实体装配、制造公差或机构运动验证。

## 文件与来源

- `models/virtual/walle-assembled.blend`：可编辑的 Blender 整机，按七个模块分组，贴图已打包；单位设置为毫米。
- `scripts/build-virtual-model.py`：确定性的装配、磨损贴图烘焙、GLB导出和四视图渲染脚本。
- `src/content/robot-rig.json`：Blender与网页共享的10个关节节点、父子关系、毫米制轴心、8组滑块及角度范围。Blender建立父子层级，GLB保留节点；网页在各节点的初始四元数上叠加相对角度。
- `src/content/robot-motion.ts`：动作序列、速度/幅度/次数/方向参数、平滑插值、姿态限制与镜像。
- `src/content/robot-timeline.ts`：姿态/预设两类步骤的编译、过渡/停留时间、预览位置，以及深复制与排序；`TimelineEditor.tsx` 提供编辑界面。
- `src/content/robot-drive.ts`：米制差速运动、加速、制动、场地边界和闭合履带路径采样；`robot-settings.ts` 管理虚拟校准、颜色及本机配置。
- `public/portfolio/virtual/`：GLB、四张预览、四种基础色贴图及 `assembly-record.json`。离线包中对应文件位于 `dist/portfolio/virtual/`。
- 装配记录逐项列出源文件、SHA-256、使用数量，以及8类推定零件和额外外观细节。52类零件全部用于装配，履带按清单使用70块板和140个销钉。

缺失的机身前板、后板、底板、头部中央支架、左右轮架与左右外轮支架共8类，使用展示用推定几何补齐。镜片、面板、通风槽、文字、轮毂端盖和顶部封板为展示细节。它们不属于原始STL，不加入60类原始目录，也不替代原文件。

整机几何按毫米解释，导出的GLB在根节点统一转换为米、Y轴向上。模型保留独立对象，重复件复用网格，通过刚体父子节点运动，无需骨骼蒙皮。头部随颈部、手掌与夹爪随手臂联动，舱门上的文字与铭牌随门移动；前板补建为带开口的框架。材质采用黄色机身、深灰履带、金属眼框、深色镜片，Cycles烘焙磨损蒙版后生成基础色贴图。GLB内嵌贴图，不依赖网络或Blender程序材质。

## 重建

需要 Blender 5.2（已在本机5.2.1后台执行）。在项目根目录运行：

```powershell
& 'C:\Program Files\Blender Foundation\Blender 5.2\blender.exe' --background --factory-startup --python scripts/build-virtual-model.py
```

脚本优先只读原始资料目录，找不到时依次使用项目 `public/portfolio/models/` 或离线包 `dist/portfolio/models/` 中的副本。不会写入原始目录。重建会覆盖当前虚拟模型、Blender源文件及预览。

仅重新渲染保存好的整机：在上面命令后追加 `-- --preview-only`。修改装配脚本并重建模型后，在完整源码项目运行 `npm run build`、`npm run package` 更新网页与离线包。离线包只附建模所需源文件；在离线包中重建后，可将 `public/portfolio/virtual/` 的输出复制到 `dist/portfolio/virtual/` 更新展示。

## 网页行为

Three.js随虚拟章节按需加载，GLB使用本机地址读取；鼠标拖动或单指旋转、滚轮或双指缩放。方向键旋转，加减键缩放，Home或按钮复位。平移和自动旋转关闭。没有交互时按需停止绘制，离开章节释放网格、材质、贴图与WebGL上下文。加载失败、WebGL不可用或上下文丢失时显示本地静态预览。

八组滑块分别控制头部左右、颈部俯仰、左右臂、左右夹爪、舱门和整机转向，零点为当前装配姿态。镜像交换左右臂/夹爪并反转头部与整机朝向；随机姿态限于演示范围。

八种预设为环顾、点头、挥手、夹爪、舱门、转身、伸臂和恢复初始。支持0.5–2倍速、1–5次重复、25–100%幅度及左右方向；方向用于环顾、挥手与转身。播放时锁定参数，点击另一动作会切换；暂停保留进度，停止保留当前姿态，复位清除动作并恢复所有关节。手动拖动滑块会接管并停止播放；隐藏页面自动暂停，离开章节取消播放。

手机布局中三维预览在控制区域悬停，调节关节或选择动作时可持续观察；320、390、768、1024与1280像素宽度均检查页面溢出。

点击“全屏工作台”进入占满浏览器窗口的工作区，作品集导航和正文暂时收起；左侧保持模型与关节控制，右侧独立滚动。切换四个页签访问“动作编排、内置动作、我的动作、校准与状态”。按Escape或“返回作品集”退出；切换布局保留相机、姿态、编排与播放状态，不重建WebGL上下文。页签支持方向键、Home和End切换，切换页签会停止当前播放。

编排支持捕获当前姿态、命名、过渡0.1–10秒、停留0–10秒、更新为当前姿态、复制、删除、拖动或按钮排序；可插入内置动作，并保存插入时的速度/次数/幅度/方向为该步骤的独立参数。“从头播放”从初始姿态执行整段；下方“播放”从当前时间轴位置继续，可暂停、停止、复位。拖动播放位置停止播放并实时采样预览。姿态步骤保持最后姿态，预设步骤沿用原有回到初始姿态的行为。支持0.5/1/1.5/2倍编排速度。

编排只存于当前组件，切换页签或进入/退出全屏保留，刷新或离开章节后清空。“我的动作”展示本页当前草稿。按用户要求跳过动作库持久保存与分享，只有校准和外观配置可以保存。

## 履带驾驶与观察

左侧切换“履带驾驶”，按住方向按钮或启用键盘W/A/S/D驾驶。W/S前后行驶，A/D原地转向，组合按键差速转弯；空格、松键、松开按钮、失焦、隐藏或离开页面、预览不可见、上下文丢失时停止。编辑文字、数值和选择框时不接管驾驶按键。独立履带滑块松开或松键归零。方向盘、手动调姿和动作播放互相接管，避免多源同时驱动。

左右履带以0.216米间距计算速度与朝向，行驶速度0.05–0.25 m/s，起步渐进，释放立即制动。车体中心限制在X/Z各±1.1米；边界制动后可转向或后退。驾驶场景显示0.1米网格，默认跟随镜头，关闭后可看机器人离开当前观察中心。位置复位返回原点与朝前，保留其他关节；“停止并复位”恢复位置和全部姿态，视角复位只重置观察相机。

357个原有展示对象中，70块履带板和140个销钉沿原闭合路径循环，轮子和齿轮按半径旋转，左右履带独立。转身姿态同样联动履带。GLB保存节点驱动属性，`public/portfolio/virtual/drive-rig.json` 保存路径；源脚本完整重建会再次生成。可用 `-- --drive-rig-only` 只为现有Blender整机更新驱动元数据，不重新渲染。

标准视角提供三分之四、正面、侧面、背面和俯视；驱动车体后仍以当前位置为观察中心。拖动模型保留自由观察，选择关节滑块或校准行会高亮对应部件，可清除高亮。相机保持在地面上方。

## 虚拟校准与外观

“校准与状态”提供零点偏移、反向和最小/最大角度。限位只能缩小原始演示范围并包含0°，偏移限定±10°；无效设置不允许应用或保存。指令先按限位裁剪，反向在设定区间内镜像，然后叠加零点偏移并再次限位。表中同时显示指令角和映射后的显示角；同一映射用于滑块、预设、随机姿态和时间轴。恢复初始姿态使用校准后的零点。

机身、履带和镜片颜色实时可调；机身与履带用原磨损纹理提取灰度，保留磨损后再着色。恢复默认外观与校准分别生效。“保存校准与外观配置”将版本1配置写入浏览器 `walle.viewer-settings.v1`，刷新或重新进入时恢复。坏配置回退默认，存储不可用时保留本次应用并显示保存失败。

操作仅作用于虚拟模型。驾驶为平面运动学演示，未做实体通信、接触力、摩擦或刚体动力学求解；结构拆解、内部电子器件仍不在本版范围内。
