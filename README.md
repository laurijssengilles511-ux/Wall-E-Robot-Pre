# 瓦力机器人课程项目作品集

《实体、结构与制造》课程小组项目。新版是以真实图文资料为主体的七章作品集，由讲解者自主切换章节；已撤下旧版自动影片、临时机器人与控制台。

## 在线访问与部署

网站地址：https://laurijssengilles511-ux.github.io/Wall-E-Robot-Pre/

网站由 GitHub Pages 托管。更新 `main` 分支后，`.github/workflows/deploy.yml` 会自动安装依赖、运行测试、构建并发布 `dist`。可在仓库的 Actions 页面查看发布进度，也可手动运行此工作流。Pages 的发布来源应保持为 GitHub Actions。

线上构建会使用仓库名作为资源基础路径；本地构建仍保留相对路径，继续支持离线展示。页面使用 `#/` 章节地址，可直接分享各章节链接。

## 打开网站

电脑安装 Node.js 22.12 或更新版本后，双击 **启动作品集.cmd**。本机服务器地址为 `http://127.0.0.1:4173`。

启动脚本兼容 Windows 内置 PowerShell 5.1。它会先确认后台服务就绪，再打开浏览器；服务日志保存在 `.runtime` 文件夹。如果页面提示拒绝连接，请重新双击启动脚本，而不只是打开地址。Windows 启动回归测试：`node --test tests/launcher.test.mjs`。

已准备完整 `dist` 时，无需安装网站依赖，断开外网仍能阅读正文、查看图片、下载模型和文档。请通过启动脚本访问，不能直接双击 `dist/index.html`。

从源码首次准备：

```powershell
npm install
npm run build
npm start
```

开发：`npm run dev`。资料完整性测试：`npm test`。浏览器验收：`npx playwright test`（本项目使用已安装的 Chrome）。依赖首次安装需要网络。

## 内容事实与来源

- 打印清单为 60 类、310 件，实体结构打印已全部完成。网页列出全部 60 类零件，并提供现有 52 份 STL 文件下载。
- 52 张零件预览均从对应真实 STL 静态渲染而来，不是临时程序模型，也不代表完整整机。
- “电路与搭建”保留原阶段接线设计；“实体成果”记录小组确认的简化电路、整机装配与测试完成情况。
- BOM 与当前方案不同，单独作为参考；前期摄像头通信设想与调整方案亦有区别。
- 小组以电影中的瓦力形象为原型进行建模与设计；小组成员和打印分工来自文档与清单。
- 头颈装配图与机身布局图用于讲解装配思路。
- 两张新图片用于外观与功能构想，不作为小组完成的工程图。
- 小组已确认缩小尺寸、简化电路后的实体整机完成组装与测试；新增成果页不补写尺寸数值、测试指标或未确认的具体功能。虚拟平台仍基于原阶段52类STL完成数字装配，含8类推定结构件，支持履带驾驶、关节动作与时间轴、虚拟校准和配色。仅校准/外观配置可保存到本机；按用户要求不制作动作库持久保存与分享。编排仍为页面草稿，真机连接未接入。

## 素材与维护

原始资料目录只读：

`D:\桌面\大二秋冬\课内课程\实体、结构与制造\Otto 机器人\瓦力机器人`

网站副本位于 `public/portfolio`。`source-manifest.json` 保存原始目录每个文件的相对路径、大小和 SHA-256；下载模型与文档的完整性通过测试核对。原文件名保留在下载文件中。

60 类清单与 52 份 STL 的差异为：机身后板、机身底板、机身前板、头部中央支架、左右外轮支架及左右轮架。目录保留这 8 类零件名称和数量，仅对已有文件提供下载。

- `src/pages/`：七章正文。
- `src/content/portfolio.ts`：导航、来源说明、成员与资源帮助函数。
- `src/content/catalog.json`：真实文件目录，由准备脚本生成。
- `src/content/model-inventory.json`：从三份打印数量清单生成的完整 60 类零件目录；运行 `python scripts/prepare-model-inventory.py` 可单独更新。
- `src/components/PortfolioParts.tsx`：图像、文档入口与电路示意。
- `src/content/robot-rig.json`：Blender与网页共用的关节轴心、父子关系、范围和驱动节点。
- `src/content/robot-motion.ts`：预设动作、参数、插值和姿态镜像；`RobotPlayground.tsx` 提供控制台，`RobotViewer.tsx` 将姿态应用到模型。
- `src/content/robot-timeline.ts`：姿态与预设步骤编译、时长和排序；`TimelineEditor.tsx` 提供时间轴、步骤编辑和播放定位。进入/退出全屏不重置编排，刷新或离开虚拟章节会清空。
- `src/content/robot-drive.ts`、`robot-settings.ts`：差速驾驶、场地边界、履带路径采样、虚拟校准和本机配置；`DrivePanel.tsx`、`ViewerSettingsPanel.tsx` 提供控制面板。
- `scripts/prepare-portfolio.py`：只读原资料，复制素材、提取文档图示并生成 STL 预览。素材准备需要 Python、numpy、matplotlib；日常看网站不需要它们。
- `scripts/serve.mjs`：无第三方运行依赖的离线静态服务器，仅接受本机连接。

更新资料后运行 `npm run assets:prepare` 再构建。准备脚本还依赖本次提供的两张参考图片路径；更换电脑时需调整这些输入路径，或者直接保留网站已打包素材，不必重新生成。

## 文件夹用途

| 文件或文件夹 | 用途 |
| --- | --- |
| `启动作品集.cmd`、`Start-Show.ps1` | 双击启动网页，兼容 Windows PowerShell 5.1 |
| `dist/` | 当前可直接展示的构建产物；不要随意删除 |
| `src/` | 七章网页源代码与样式 |
| `public/` | 当前使用的图片、52 个 STL、预览与原始文档副本 |
| `scripts/` | 本地服务、素材准备、截图检查和离线包生成 |
| `tests/` | 资料完整性、网页交互和启动脚本测试 |
| `docs/` | 使用说明、验收记录与未来模型准备说明 |
| `delivery/` | 一份最新的离线作品集 ZIP |
| `node_modules/` | 开发与构建依赖；Three.js 用于虚拟模型与关节动作展示 |
| `.runtime/` | 启动服务自动生成的日志与进程记录 |

旧自动演出源码、旧模型与备份、过期放映包及调试产物已清理。当前虚拟装配的来源、补建说明与重建方法见 `docs/MODEL.md`。可编辑整机源文件在 `models/virtual/walle-assembled.blend`，装配脚本为 `scripts/build-virtual-model.py`。截图检查或浏览器测试可能重新生成 `artifacts/`、`test-results/`，这些是可删除的验证产物。

上课前请检查实际电脑、投影字幕、全部章节、图纸放大和文件下载。离线包为 `delivery/瓦力机器人-课程作品集.zip`。修改网页后依次运行 `npm run build` 和 `npm run package`，会生成最新离线包，不保留重复的解压目录。
